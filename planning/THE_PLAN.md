## MVP Checklist

This is the bare minimum we'll need to get done for the presentation:

- User login and registration
    - details: username, email, password
    - Account setup with accessibility needs

- Map display
    - Map shows on the screen
    - Map is scrollable
    - Can click on buildings to see information

- Search feature
    - Can search for businesses / addresses
    - Filterable - inaccessible businnesses show up greyed out
    - Filter defaults to account requirements

- Building display
    - Shows available ammenities
    - Shows reviews from other users
    - Has a rating given for accessibility

- Business accounts
    - Link account to business
    - Can see visitor metrics - number of missed clients etc
    - Get recommendations on how to improve
